    Model setup
    Check the local Ollama service or the configured Gemini models.
    
        
    
          
    Local Ollama · DeepSeek-R1
    
            
    Start Ollama and install the default model with ollama pull deepseek-r1:8b. The access check looks for the installed model without generating content.
    
          
    
          
        
    
        
    
          
    Gemini key setup
    
            
    Configure the Gemini key in the repository’s .env file using GEMINI_API_KEY or GOOGLE_API_KEY. The access check uses model metadata and zero generation tokens.
    
            
    Live testing needs an eligible model and available project quota. Check the tier and limits in Google AI Studio.
