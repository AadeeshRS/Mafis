# MAFIS — Phased Build Plan v1.1

> Complete and verify each phase before moving to the next. The literature review specifically warns that extra agents and critique are not guaranteed to improve every task.

| Phase | File | Goal |
|---|---|---|
| 1 | `phase-1-core-mvp.md` | Stable RAG + Document Agent + Financial Agent + Deterministic Engine + Shared Memory + Report Generation + baseline |
| 2 | `phase-2-reasoning-layer.md` | Verification, Market/Risk analysis, retrieval measurement, support labels, and Health Gate |
| 3 | `phase-3-novelty-layer.md` | Bull/Bear, structured Critic, evidence-gap handling, and capped targeted re-analysis |
| 4 | `phase-4-evaluation.md` | Baseline, expanded ablations, retrieval/verification metrics, human evaluation, latency/cost |

Exit each phase with a working, demoable system. Do not add later-phase mechanisms simply because the earlier phase is incomplete.
